About:
Cylinder 3d Blast 2 is a sequel to the original Cylinder 3d Blast, it's an isometric 3d platformer where you collect coins and dodge fire on the way to the end of the level marked by the large shiny coin.

Controls:
WASD and Arrow Keys to Move.
Space to Jump and to Navigate the Title Screen.
Escape Key to Exit.
